5 Biodata studio — the thing that gets forwarded

A biodata leaves the platform the moment it is shared — so what it contains is a privacy decision, not a formatting one. Three templates, a bilingual switch, and a set of disclosure controls that default to the careful choice: photo locked, address to district only, contact never printed. Every share is a 7-day link, not a file, so it can be revoked.
