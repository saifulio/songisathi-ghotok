------------------------------------------------------------------------------
  SIGN IN / SIGN UP  (auth API + pages)
------------------------------------------------------------------------------
  · Pages:   /signin  and  /signup   (linked from the top-right of the nav)
  · Sign up as: Matchmaker · Guardian · Bride (self) · Groom (self)
      - Bride/Groom collect biodata (DOB, height, district, area, degree,
        institution, profession, family type, religion, practice) and create a
        self-managed Profile + CANDIDATE login.
  · The /signin page has one-click "Demo account" chips (the accounts above).
  · API server: server/index.js  (Express, port 4000). Endpoints:
      POST /api/auth/signup   POST /api/auth/signin   GET /api/auth/me
    Passwords are bcrypt-checked; a JWT is returned and stored in the browser.

  RUN BOTH (web + api together):   npm run dev:all
    or in two terminals:           npm run server    and    npm run dev
  (The Vite dev server proxies /api → http://localhost:4000.)

------------------------------------------------------------------------------
  DATABASE COMMANDS
------------------------------------------------------------------------------
  1. Configure connection:   edit .env  →  DATABASE_URL
     (default: mysql://root:@localhost:3306/songisathi-ghotok)

  2. Create DB + run migrations:   npm run db:migrate
     (or, for a dev workflow with a new migration:  npm run db:migrate:dev)

  3. Populate sample data:         npm run db:seed

  4. Reset everything (drop, re-migrate, re-seed):  npm run db:reset

  5. Browse the data visually:     npm run db:studio   (opens Prisma Studio)

  Migrations live in: prisma/migrations/   (checked in, version-controlled)
  Schema:             prisma/schema.prisma
  Seed script:        prisma/seed.mjs
